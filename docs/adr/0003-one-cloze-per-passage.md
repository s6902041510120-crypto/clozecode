# หนึ่ง Passage มีหนึ่งช่องว่างเสมอ

Passage ทุกชุดมีช่องว่างเดียว ผู้เล่นกูคำได้หนึ่งคำต่อหนึ่ง Passage ไม่มีแบบหลายช่องว่าง
ในหน้าจอเดียว

เหตุผล: UI ง่ายพอที่จะทำเสร็จได้ใน v1 และผู้เล่นเห็นชัดว่าต้องกู้คำเดียว ทำให้จำนวน
Passage ที่ 30–50 ชุดคุณภาพดีเป็นไปได้เร็วกว่าการทำ UI รองรับหลาย input ซึ่งซับซ้อนกว่า

ถ้าภายหลังต้องการ Passage แบบหลายช่องว่าง ต้องเปลี่ยนโครงสร้างข้อมูลและ UI ทั้งหมด
จึงตั้งใจออกแบบให้ขยายได้แต่ไม่ทำไว้ล่วงหน้า
