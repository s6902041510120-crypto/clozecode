# จบหัวข้อเมื่อ Lives หมด แต่ต้อง Review ก่อน

ตัดสินใจให้ Lives มีผลจริง ๆ โดยหมด 3 ครั้งแล้วหัวข้อจบลง แต่หน้าจอ Review ที่แสดง
คำตอบที่พลาดทั้งหมดพร้อมคำอธิบายจะต้องผ่านก่อนออกไปหัวข้อถัดไป เพราะเกมนี้มีจุดประสงค์คือ
สอนศัพท์ ไม่ใช่แค่วัดผล

ผลที่ตามมา: ผู้เล่นหมด Lives ไม่ได้แปลว่าเล่นต่อไม่ได้ ต้องดู Review ให้เสร็จก่อน ซึ่งทำให้
คะแนนหัวข้อนั้นต่ำแน่นอน — เป็นตัวกำหนดอันดับโดยไม่ต้องมีกติกาหักคะแนนเพิ่ม
