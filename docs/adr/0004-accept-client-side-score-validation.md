# ยอมรับการตรวจคะแนนฝั่ง client ไม่มี Cloud Function

Firestore rules จะอนุญาตให้ client เขียนคะแนนของตัวเองได้ ไม่มี Cloud Function มาคำนวณซ้ำ
ฝั่งเซิร์ฟเวอร์ แปลว่าผู้เล่นแก้คะแนนผ่าน DevTools แล้วขึ้นอันดับ 1 ได้

เหตุผล: คะแนนที่แซงได้ไม่ทำให้ผู้เล่นคนอื่นเสียหายอะไรนอกจากเสียเวลา เพราะเกมนี้ไม่มีรางวัล
มูลค่าจริงและไม่มีเงินจริง เขียน Cloud Function เพิ่มจะได้คะแนนที่เชื่อถือได้จริงแต่เพิ่มค่าใช้จ่าย
read และความซับซ้อนที่ไม่ได้ทำให้ผู้เล่นเล่นสนุกขึ้น

ข้อแลกเปลี่ยนที่ยอมรับ: ลีดเดอร์บอร์ดนี้ไม่ใช่ระบบจัดอันดับที่ป้องกันการแซง หากภายหลังเพิ่มรางวัล
เงินจริงหรือรายการอันดับที่ต้องซื่อเสียง ต้องย้อนมาแก้เรื่องนี้ก่อน
