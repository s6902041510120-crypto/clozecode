# สลับลำดับ Passage แบบ deterministic จาก Player Code

ลำดับ Passage ที่ผู้เล่นเจอไม่ได้สุ่มสดทุกครั้ง แต่เรียงตาม seed ที่คำนวณจาก Player Code
ของผู้เล่น ทำให้แต่ละคนเจอลำดับต่างกัน แต่คนเดิมเล่นหัวข้อเดิมซ้ำจะได้ลำดับเดิมเสมอ

เหตุผล: ลีดเดอร์บอร์ดเทียบคะแนนระหว่างผู้เล่น ถ้าสุ่มอิสระคนหนึ่งอาจโชคดีเจอโจทย์ง่ายก่อน
แล้วชนะไปด้วยโชค เมื่อ seed เป็นฟังก์ชันของ Player Code ทุกคนต้องเจอชุดโจทย์เดียวกัน
เพียงแต่คนละลำดับ ทำให้คะแนนเทียบกันได้

ข้อแลกเปลี่ยน: ถ้าเพิ่มหรือลดจำนวน Passage ในหัวข้อ ลำดับของทุกคนจะเปลี่ยนหมด
และคะแนนเก่าเทียบกับคะแนนใหม่ไม่ได้
