# ใช้ Firebase Firestore เก็บคะแนนลีดเดอร์บอร์ด

ลีดเดอร์บอร์ดต้องเก็บและเทียบคะแนนข้ามเครื่อง ซึ่ง Vite + React เป็น frontend อย่างเดียวจึงต้องมี
ที่เก็บข้อมูลฝั่งเซิร์ฟเวอร์ เลือก Firestore แทน Supabase ทั้งที่โปรเจกต์ mindmatch ในเครื่องนี้ใช้
Supabase — เลือกข้ามเพื่อไม่ให้ผูกติดกับ stack เดิมของอีกโปรเจกต์ และเพราะ Firestore จ่ายตาม
read/write ซึ่งเหมาะกับปริมาณของเกมที่เล่นเป็นครั้ง ๆ

ข้อแลกเปลี่ยน: ต้องตั้ง Firebase config ผ่าน environment variable ตอน build และมีขั้นตอนตรวจสอบ
กติกาคะแนนฝั่ง client ก่อนบันทึก เพราะ client ควบคุมตัวเลขที่ส่งขึ้นไปได้
